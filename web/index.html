Can Fundamental Cause Theory explain the Alcohol Harm Paradox?

People in more deprived areas suffer more alcohol-related harm, even when they drink the same or less. This is a complex-systems model of 1,000 people on a simple town map. Run it, change the assumptions, and see whether that paradox emerges.

What is going on?

The paradox

The Alcohol Harm Paradox (AHP) is the observation that people with low socioeconomic status suffer more alcohol-related harm across their lives than wealthier people, even when drinking the same amount or less. In Scotland, alcohol-specific deaths in the most deprived fifth of the population run several times higher than in the least deprived fifth.

The theory

Fundamental Cause Theory (FCT) proposes that socioeconomic resources such as education, money, power and social prestige are the fundamental cause of health inequality. They are flexible resources that people can use to dodge risks and adopt protections, whatever the specific disease is. The model asks whether that idea alone can reproduce the AHP.

The method

The model is built with Mechanism-Based Social Systems Modelling, which links a society-level layer to individual behaviour through three kinds of mechanism. It was written in Python with Repast4Py and explored with 200 Latin-hypercube simulations. This page is a port of that model to JavaScript.

One week in the model

  1. Situational

    A communicator (think health campaign) broadcasts a random 5-bit message to a random subset of people. The message’s value is how many resources it takes to act on it.

  2. Action

    Each person tries to act on one pending message. They succeed if their resources (knowledge + wealth + prestige + power) cover it. Successful people pass the message to a friend. Everyone drinks according to their own habit, and that carries risk.

  3. Transformational

    Once a year people age, some swap places with someone from a more (or less) deprived quintile, in equal numbers after Giorgi et al., and “die” if their personal risk crosses the threshold. A death resets the person to age 18.

What the dissertation found

Across 200 runs the AHP signature (all three gradients with the expected sign) appeared in just one, Simulation 5. When that run was extended from 520 to 1,200 weeks the signature disappeared. The conclusion was that FCT as implemented here does not reliably produce the AHP. The model is best read as a platform for asking which extra mechanisms would be needed. Try “Run 20 seeds” on each scenario and see how fragile the pattern is.

Implementation notes and differences from the Python model
  • This is a re-implementation, not a bit-for-bit replay. It uses its own random-number generator, so a given seed will not match a Python run.
  • Deaths are counted as raw events, attributed to the quintile a person lives in at that moment. The dissertation’s plots summed a cumulative counter, so its totals are larger; only the sign of each gradient is comparable.
  • Gradients are least-squares slopes of each measure against quintile number 1 to 5.
  • The friendship network links people in the same quintile and within five years of age whenever possible, which is the effective rule in the Python code. This port builds it directly rather than by rejection sampling.
  • As in the Python code, adaptation costs do not carry over from week to week, and a friend who has not yet solved any message cannot receive one from a peer.
  • The dissertation describes age-dependent swapping (under-30s tend to move to more deprived quintiles). The Python code, and so this port, swaps by quintile only.
  • “Death” is really a harm event: the person re-enters the population at age 18.
